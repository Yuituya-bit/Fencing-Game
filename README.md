# Fencing-Game
ProcessingとArduino、UDP無線通信を用いた二人対戦の剣劇アクションゲーム

## 概要
侍を操作し、間合いやガード、攻撃の駆け引きを楽しむ対戦ゲーム

- 対戦：攻撃・移動・ガードを駆使したリアルタイム対戦。ガードのスタミナ制限の中で読み合いを行う
- ハードウェアとの連携：Arduinoのシリアル通信とUDP無線通信による外部コントローラ操作に対応
- Minimライブラリによる音楽や効果音
- 相打ち時の隠し演出を実装

## 担当
- ゲーム側のメインプログラムの実装
- シリアル通信及びUDP無線通信の受信側処理の構築
- 当たり判定やガードゲージ等のアニメーションフォント処理

## 環境
- 言語：Processing 3

## 主要ライブラリ
　- `processing.serial`(Arduinoシリアル通信受信)
  - `hypermedia.net.*`(UDP無線通信受信)
  - `ddf.minim.*`(サウンド再生)
  - `org.gamecontrolplus.*`(コントローラ制御)
  - `controlP5.*`(UI制御)
